# API Development Skill

## 🎯 Role
Design and implement secure, scalable APIs using Next.js Route Handlers with clean architecture and validation.

---

## 🚀 Best Practices
- Use Route Handlers instead of legacy API
- Validate all inputs
- Use proper status codes
- Sanitize database input
- Avoid exposing secrets
- Centralize error handling

---

## ⚡ Standard Response Format
{
"success": boolean,
"message": string,
"data": any
}
