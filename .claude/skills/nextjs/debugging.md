# Debugging Skill

## 🎯 Role
Identify, analyze, and resolve issues using structured debugging strategies.

---

## 🧠 Debugging Process
1️⃣ Reproduce the issue  
2️⃣ Identify scope  
3️⃣ Check logs / console  
4️⃣ Isolate problem  
5️⃣ Apply fix  
6️⃣ Retest  
7️⃣ Prevent regression  

---

## 🔥 Best Practices
- Read error carefully
- Check environment
- Debug both backend + frontend
- Use logging
- Validate assumptions
